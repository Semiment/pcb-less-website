霍尔开关

磁场极性触发、输出为开关量的一类器件。按输出通道与触发方式分锁存、双路、全极 / 单极 / 微功耗、两线电流型四类，用于无刷电机换相、转速与转向检测、盖板与门位检测。

本组品类

锁存霍尔15 款在库磁极由 N 翻到 S 才翻转输出状态，输出具备记忆特性——为无刷电机换相、转速与方向检测提供稳定开关。 双路霍尔效应输出8 款在库单颗锁存器件提供双通道磁场信息——速度+速度 / 速度+方向，用于转速与转向识别、编码盘检测及执行器行程反馈。 全极 / 单极 / 微功耗霍尔开关22 款在库全极型 N / S 两极均可触发、安装磁极方向不受限；单极型只对指定磁极响应；微功耗型把平均电流降到微安级，适配常电电池供电。用于换挡器、门锁、座椅与限位到位检测。 两线霍尔电流型开关11 款在库以电流高低两态输出开关信号，一根线即可传输状态并兼做开短路诊断；集成电容与 TVS 的 PCB-less 封装可省去板上外部元件。用于安全带卡扣、座椅与单点位置检测。
