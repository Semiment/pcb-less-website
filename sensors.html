产品中心 · 磁传感与位置检测

传感器

锁存型霍尔器件需要 N / S 极交替经过感应面，输出状态随磁极翻转——为无刷电机换相、转速/方向检测与位置记忆提供稳定的磁场开关方案。

按小类选型

不同类型的传感器参数完全不同，因此每个小类独立成页，参数列按该小类的实际规格设定。点分组名先看该组全貌，点具体品类看完整参数表。

霍尔开关3 个子品类 · 46 款在库

锁存霍尔 IC15 款在库磁极由 N 翻到 S 才翻转输出状态，输出具备记忆特性——为无刷电机换相、转速与方向检测提供稳定开关。 双路霍尔效应输出8 款在库单颗锁存器件提供双通道磁场信息——速度+速度 / 速度+方向，用于转速与转向识别、编码盘检测及执行器行程反馈。 全极 / 单极霍尔 IC23 款在库全极型 N / S 两极均可触发、安装磁极方向不受限；单极型只对指定磁极响应。用于盖板开合、门禁与位置到位检测。

位置传感器3 个子品类 · 36 款在库

线性霍尔（1D）20 款在库输出随磁场强度线性变化，用于电流检测、位移与角度反馈等需要连续量输出的场合。 可编程线性霍尔5 款在库灵敏度与零点可编程，适配不同磁路与量程，用于精密位置与电流检测。 角度传感器（单轴 / 多轴）11 款在库非接触测量绝对角度（磁性 / 电感式两种原理），用于转向角、踏板与电机转子位置。

速度传感器5 个子品类 · 26 款在库

轮速传感器9 款在库检测齿圈转速并以电流或电压脉冲输出，用于轮速采集与整车安全控制。 变速箱传感器7 款在库检测变速箱转速与挡位位置，用于换挡控制与转速闭环。 凸轮轴传感器4 款在库检测凸轮轴相位，用于发动机正时与气门控制。 曲轴传感器3 款在库提供转速与相位基准，用于点火与喷油时序。 齿轮传感器3 款在库齿轮转速与方向检测，用于传动系统测速与计数。

编码器2 个子品类 · 11 款在库

磁性电机编码器6 款在库磁性非接触编码，输出 ABZ / UVW / PWM / SIN-COS，用于电机换相与闭环控制。 电感式电机编码器5 款在库电感式非接触编码，不受外部磁场干扰，用于高转速电机位置反馈。

电流与保护2 个子品类 · 4 款在库

单片式电流传感器2 款在库集成霍尔电流检测，用于电机相电流与母线电流采样。 漏电保护2 款在库漏电流检测专用 IC，用于漏电保护器与安全回路。
